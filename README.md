# Python for Data Engineering

Repositório dedicado ao estudo e desenvolvimento de projetos em Python aplicados à Engenharia de Dados.

O objetivo deste roadmap é consolidar conhecimentos fundamentais da linguagem Python e evoluir gradualmente para a construção de pipelines de dados, integrações com bancos de dados, consumo de APIs e processos ETL, simulando atividades comuns da rotina de um Engenheiro de Dados Júnior.

---

## Tecnologias e Ferramentas

* Python
* Pandas
* NumPy
* SQL
* APIs REST
* ETL (Extract, Transform, Load)
* Git e GitHub

---

## Estrutura do Roadmap

### Bloco 1 - Python para Dados

Fundamentos da linguagem Python aplicados ao contexto de dados:

* Estruturas condicionais
* Estruturas de repetição
* Funções
* Listas, tuplas, conjuntos e dicionários
* Manipulação de arquivos
* Validação e limpeza de dados
* Mini pipeline de processamento

### Bloco 2 - Pandas e NumPy

Manipulação e análise de dados utilizando bibliotecas amplamente utilizadas no mercado:

* Series e DataFrames
* Filtragem e seleção de dados
* Agrupamentos e agregações
* Junções de tabelas
* Análise exploratória
* Projeto analítico

### Bloco 3 - Python, SQL e APIs

Integração entre diferentes fontes de dados:

* Conexão com bancos de dados
* Execução de consultas SQL via Python
* Consumo de APIs REST
* Tratamento de respostas JSON
* Integração de múltiplas fontes
* Construção de pipelines de dados

### Bloco 4 - ETL Profissional

Aplicação dos conhecimentos adquiridos em um fluxo completo de dados:

* Extração de dados
* Transformação de dados
* Carga de dados
* Modularização do código
* Boas práticas de desenvolvimento
* Projeto final

## Objetivo Profissional

Este repositório faz parte da minha preparação para atuar na área de Engenharia de Dados, reunindo exercícios, estudos práticos e projetos desenvolvidos durante a jornada de aprendizado.

Cada bloco representa uma etapa da evolução técnica, desde os fundamentos da linguagem até a construção de soluções completas de processamento de dados.
